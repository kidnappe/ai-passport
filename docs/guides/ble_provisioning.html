⚠️ 浏览器不支持 Web Bluetooth

请使用以下浏览器之一：

  • Chrome 56+ (Android/Windows/Mac/Linux)
  • Edge 79+ (Windows/Mac)
  • Opera 43+
  • Samsung Internet 6+

iOS Safari 暂不支持 Web Bluetooth API
请使用安卓手机或电脑端 Chrome/Edge

使用方法: 用 Chrome/Edge 打开本文件即可
手机也可用本地服务器访问: 

npx serve .
# 或
python -m http.server
