AI Passport BLE 配网教程

1下载 nRF Connect

手机打开应用商店，搜索 nRF Connect 并安装（Nordic Semiconductor 出品，免费）。

2打开配网页面

设备上进入 设置 → WiFi 配网，按 OK 键启动蓝牙广播。

屏幕显示 热点已开启 即表示设备正在广播。

3连接设备

打开 nRF Connect，点击右上角 SCAN。

在列表中找到 AI-Passport，点击 CONNECT。

4写入 WiFi 名称

连接后，在 Unknown Service 下找到第一个可写的特征（UUID 结尾 0002）。

点击它 → Write → 输入你的 WiFi 名称 → Send。

5写入 WiFi 密码

找到第二个可写的特征（UUID 结尾 0003）。

点击 → Write → 输入 WiFi 密码 → Send。
开放网络可留空或写一个空格。

6触发连接

找到第三个可写的特征（UUID 结尾 0004）。

点击 → Write → 输入 01 → 选择 Hex 格式 → Send。

设备收到后会自动连接 WiFi，屏幕显示配网结果。

提示：
• 三个特征必须按顺序写入：SSID → 密码 → 0x01
• 写入 0x01 时记得选 Hex 格式，不是 Text
• 配网成功后设备会重启 BLE 插件服务，可正常安装插件
• 配网失败可长按 OK 取消重试
